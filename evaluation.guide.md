Introdução
Por favor, siga as seguintes regras:

- Mantenha-se educado, cortês, respeitoso e construtivo durante todo o
processo de avaliação. O bem-estar da comunidade depende disso.

- Identifique, junto com o aluno ou grupo cujo trabalho está sendo avaliado, as possíveis
disfunções em seu projeto. Dedique um tempo para discutir e debater os
problemas que possam ter sido identificados.

- Você deve considerar que pode haver diferenças na forma como seus colegas entenderam
as instruções do projeto e o escopo de suas funcionalidades.
Mantenha sempre a mente aberta e avalie-os da forma mais honesta possível.
A pedagogia só é eficaz se a avaliação por pares for feita com seriedade.

Diretrizes
- Avalie apenas o trabalho que estiver no repositório Git do
aluno ou grupo avaliado.

- Verifique cada etapa cuidadosamente e teste minuciosamente.

- O projeto deve atingir pelo menos 14 pontos de módulo para ser aprovado.

- Consulte o arquivo README.md para obter a lista de módulos escolhidos e suas justificativas.

- Todos os membros da equipe devem estar presentes e participar da avaliação.

- Verifique novamente se o repositório Git pertence ao(s) aluno(s). Certifique-se de que
o projeto seja o esperado. Verifique também se o comando 'git clone' foi usado em uma
pasta vazia.

- Verifique cuidadosamente se nenhum aliase malicioso foi usado para enganá-lo e fazer com que você
avalie algo que não corresponde ao conteúdo do repositório oficial.

- Para evitar surpresas e, se aplicável, revise em conjunto quaisquer scripts usados
​​para facilitar a avaliação (scripts para teste ou automação).

- Se você não concluiu a tarefa que irá avaliar, leia
todo o conteúdo do documento antes de iniciar o processo de avaliação.

- Use as flags disponíveis para relatar um repositório vazio, um programa que não funciona
, um erro de norma, fraude, etc.
Nesses casos, o processo de avaliação termina e a nota final é 0,
ou -42 em caso de fraude. No entanto, exceto em casos de fraude, os alunos são
fortemente encorajados a revisar juntos o trabalho entregue, a fim
de identificar quaisquer erros que não devem ser repetidos no futuro.

Caso todos os pontos obrigatórios não tenham sido atingidos durante a defesa, os pontos bônus devem ser totalmente ignorados. Pontos bônus são concedidos para módulos além dos 14 pontos exigidos.
