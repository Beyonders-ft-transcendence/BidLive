Serviços:

Usar uv dentro do container.

Basear o Dockerfile aproximadamente nesta ideia, mas modernizando e adaptando para uv:

```dockerfile
FROM alpine:3.22

ENV PYTHONDONTWRITEBYTECODE=1
ENV PYTHONUNBUFFERED=1

RUN apk add --no-cache \
    python3 \
    py3-pip \
    build-base \
    netcat-openbsd \
    postgresql-dev \
    libffi-dev \
    jpeg-dev \
    zlib-dev

WORKDIR /app

COPY pyproject.toml uv.lock ./

# instalar uv
RUN pip install uv

# instalar dependências
RUN uv sync --frozen

COPY . .

COPY ./tools/entrypoint.sh /entrypoint.sh
RUN chmod +x /entrypoint.sh

ENV PATH="/app/.venv/bin:$PATH"

EXPOSE 8000

ENTRYPOINT ["/entrypoint.sh"]
```

O entrypoint.sh deve:
- esperar PostgreSQL iniciar
- executar migrations
- executar collectstatic
- iniciar aplicação
- ser robusto e organizado
